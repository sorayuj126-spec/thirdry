# ソリティア (Klondike Solitaire) - MVP

HTML5 / CSS3 / JavaScript (バニラJS) で制作されたクラシックなソリティア（クロンダイク）のWebアプリケーションです。
外部ライブラリに依存せず、PC・スマートフォンの両方で軽快にプレイできます。

## 🎮 公開URL (GitHub Pages)

https://sorayuj126-spec.github.io/thirdry/

## ✨ 主な機能・特徴

- **ドラッグ＆ドロップ & タップ操作両対応**:
  - カードをドラッグして直感的に移動可能（Pointer Events対応）
  - カードをタップするだけで、置ける場所へ自動移動（スマートムーブ）
  - カードを選択し、目的の列・スロットをタップして配置する操作にも対応
- **山札（1枚めくり） & 再循環**:
  - 山札をクリックすると捨て札へ1枚めくられます
  - 山札が空になったらリセットアイコンをクリックして捨て札を裏返し再循環
- **4つの組札 (Foundation)**:
  - ♠ ♥ ♦ ♣ の各スートごとに、Aから順にKまで重ねて完成を目指します
- **7つの場札 (Tableau)**:
  - 異なる色（赤・黒）で数字が1つ小さいカードを降順に重ねて配置可能
  - 表向きのカード束をまとめて移動可能
  - 空いた列にはキング（K）のみ配置可能
- **アンドゥ（戻す）機能**:
  - 過去の手を何手でも1手ずつやり直せます
- **ヒント機能**:
  - 現在の手詰まり解消や次に可能な手を黄色いハイライトでお知らせ
- **自動完成（オートコンプリート）機能**:
  - すべてのカードが表向きになった段階で「⚡ 自動完成」ボタンが出現し、残りのカードを自動で組札へ送ってスピーディーにクリア
- **クリア演出**:
  - 4組完成時に華やかな紙吹雪アニメーションとタイム・手数のリザルト表示
- **レスポンシブデザイン**:
  - スマートフォン、タブレット、PCの画面サイズに合わせて自動でカードサイズが最適化
